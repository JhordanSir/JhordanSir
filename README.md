## 🚀 Trabajo y proyectos principales

### 🚕 Sirio Express
**Plataforma Android nativa para conectar pasajeros con taxistas cercanos.**

- Desarrollada con **Kotlin + Jetpack Compose** y backend en **NestJS**.
- Ubicación del conductor y estados de viaje en tiempo real mediante **Socket.IO + Redis**.
- Consultas espaciales de proximidad usando **PostgreSQL + PostGIS**.
- Mapas con **MapLibre**, **TileServer** propio y cálculo de rutas con **OSRM**.
- Notificaciones push mediante **Firebase Cloud Messaging** y chat pasajero ↔ conductor dentro de la aplicación.
- Flujo de registro, revisión y aprobación de conductores junto con panel administrativo.
- Infraestructura backend desplegada con **Docker + Dokploy** sobre un VPS Linux.
- El archivo **AAB** ya fue subido al canal de prueba cerrada de Google Play.

**Stack:** Kotlin · Jetpack Compose · NestJS · PostgreSQL · PostGIS · Redis · Socket.IO · Firebase · MapLibre · OSRM · Docker

### ⚙️ Sirio Automatiza
**Proyecto independiente de desarrollo de software y automatización para negocios reales.**

Diseño, despliego y mantengo sistemas utilizados en operaciones diarias de empresas de transporte, minería y comercio electrónico.

#### Global Móbil del Sur
- Digitalicé el flujo de despacho y venta de pasajes para la operación de transporte **Chala ↔ Camaná**.
- El sistema gestiona colas de vehículos, selección de asientos, pasajeros, impresión de tickets térmicos, reportes, permisos, oficinas y flujos para socios y conductores.
- Se utiliza diariamente para gestionar aproximadamente **10–12 salidas de vehículos por día**.
- Desplegado y mantenido en mi VPS.

**Stack:** Angular · TypeScript · NestJS · Prisma · PostgreSQL · Docker · Dokploy

#### Goldmine
- Sistema de gestión operativa para una planta de procesamiento de oro en Chala.
- Reemplazó cuadernos y registros manuales con módulos para lotes de mineral, pozas de procesamiento, inventario/Kardex, gastos, cobranzas, proveedores, trabajadores y rentabilidad.
- Incluye trazabilidad de insumos controlados, tarifas históricas, documentos y reportes para gestión.
- Utilizado diariamente por el negocio.

**Stack:** React · TypeScript · NestJS · Prisma · PostgreSQL · Docker · Nginx · Dokploy

#### Caja de Pandora
- Automaticé la primera respuesta a consultas de WhatsApp generadas por **Facebook Ads**.
- Construí un flujo orientado a eventos utilizando **YCloud + webhooks + n8n** para identificar automáticamente el anuncio y producto de origen.
- Procesa **más de 40 mil mensajes mensuales provenientes de anuncios de Facebook**.
- Desarrollé un dashboard para analizar demanda de productos, volumen de mensajes, horarios, métricas de respuesta y rendimiento de cinco números de WhatsApp.
- Cuando el cliente responde, un vendedor humano continúa la conversación.

**Stack:** n8n · YCloud · React · TypeScript · Express · PostgreSQL · Webhooks · Docker

## 🧪 Proyectos académicos y técnicos

### 📊 DataCo Supply Chain — Minería de Datos y Analítica Visual
- Analizamos **180 519 órdenes de cadena de suministro** e integramos información arancelaria AHS.
- Participé en la limpieza de datos y en la aplicación de **PCA, UMAP, K-Means y KNN**.
- El proyecto procesó la información hasta obtener **254 segmentos producto × mercado** para análisis exploratorio.
- Se desarrolló un flujo de analítica visual basado en **FastAPI + D3.js**.
- También contribuí con el informe técnico, documentación y parte de la exposición.

**Stack:** Python · FastAPI · PCA · UMAP · K-Means · KNN · D3.js · CRISP-DM

### 📦 Rappi2 — Plataforma de Logística
- Participé como **Backend Developer** en una plataforma académica full stack de logística.
- Implementé módulos para **clientes, conductores, vehículos, registro de pagos, facturas, incidencias y archivos de evidencia**.
- Trabajé con **PostgreSQL** para datos transaccionales y **MongoDB/GridFS** para información operativa y evidencias.
- Colaboré en consultas, agregaciones y KPIs para reportes.
- La plataforma fue contenerizada y desplegada en un VPS.

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · MongoDB · GridFS · Docker · Dokploy
